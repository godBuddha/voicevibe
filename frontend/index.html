Credits tiêu theo từng loại job (admin đổi được qua Settings):

🔌 API cho nhà phát triển

REST API chuẩn — tài liệu tương tác (Swagger):

Mở /docs (Swagger UI) →

Ví dụ tạo job dub:
curl -X POST $BASE/v1/jobs \
  -H "X-API-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"type":"dub","media_url":"media/.../file.mp4",
       "source_lang":"vi","target_lang":"en"}'
Webhook: set webhook_url khi tạo job để nhận kết quả.
